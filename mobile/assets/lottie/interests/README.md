# Interest picker animations

One Lottie JSON per `UserInterest` value, named after `UserInterest.lottieAsset`.
Download from https://lottiefiles.com (search terms suggested) and save as:

| File                   | Suggested search        |
| ---------------------- | ----------------------- |
| school.json            | graduation cap / school |
| community.json         | community / people      |
| emergency.json         | alert / siren           |
| donation_drive.json    | donation box            |
| charity.json           | heart hands / giving    |
| relief_program.json    | package / relief        |
| health.json            | medical / heartbeat     |
| outreach.json          | handshake               |
| training.json          | tools / workshop        |
| seminar.json           | presentation / speaker  |
| others.json            | sparkles / more         |

Any file that is missing falls back to the Material icon, so the picker still
renders while the set is incomplete.
